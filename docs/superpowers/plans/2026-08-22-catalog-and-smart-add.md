# MCP Manager — Plan 4: Catalog + smart add (inspect URL, auto-auth)

**Trigger:** adding PostHog by pasting its docs URL produced a server pointing at an HTML page; Test returned 405. Adding must validate the endpoint, detect auth, and the registry should be searchable in-app.

**Goal:** (1) search the official MCP registry + a curated list and add from there; (2) when a remote URL is added, the daemon inspects it: endpoint or not, transport (streamable HTTP vs legacy SSE), auth required (OAuth metadata / WWW-Authenticate) and sets `auth` automatically; (3) the Add sheet shows the inspection live and blocks obviously wrong URLs with a suggestion.

## Stream A — daemon/core

1. `Sources/MCPMGateway/Probe/MCPProbe.swift`: add `inspect(url:timeout:) async -> URLInspection` — `{ verdict: .mcpEndpoint | .notMCP | .unreachable, transport: http|sse?, authRequired: Bool, authKind: none|oauth|header, resourceMetadataURL?, serverName?, serverVersion?, toolCount?, statusCode?, contentType?, suggestion: URL?, detail: String }`. Logic: POST initialize (Accept json+sse). 2xx JSON-RPC → endpoint/http. 401/403 → endpoint + authRequired; parse `WWW-Authenticate` `resource_metadata=` or try PRM discovery (`discoveryCandidates`) → oauth if an AS is found, else header. 405/404/HTML body → notMCP; try GET with `Accept: text/event-stream` on the same URL and on `<origin>/sse`: if `text/event-stream` with an `endpoint` event → endpoint/sse. Suggestions when notMCP: candidates `<origin>/mcp`, `https://mcp.<rootDomain>/mcp`, `https://mcp.<rootDomain>/sse` (probe each briefly, first that verifies wins). Also support the **legacy SSE transport** in `MCPProbe.remote` (GET → `endpoint` event → POST messages, read responses from the stream) so Test works on `/sse` servers.
2. Catalog: `Sources/MCPMDaemon/CatalogService.swift` — bundled `Catalog/servers.json` (curated ~25: notion, linear, github, posthog, figma, slack, sentry, stripe, supabase, vercel, cloudflare, atlassian, asana, hubspot, context7, exa, playwright, filesystem, fetch, memory, sequential-thinking, puppeteer, postgres, sqlite, git; each `{slug,name,description,kind,url?,transport?,command?,args?,auth,homepage,iconDomain}`) + live `GET https://registry.modelcontextprotocol.io/v0/servers?search=<q>&limit=30` normalized into the same `CatalogEntry` shape: prefer `remotes[0]` (kind remote, transport from `remotes[0].type`), else first package with runtimeHint npx/uvx (`command`=hint, args `["-y", identifier]` for npx / `[identifier]` for uvx), skip oci-only; dedupe by `server.name` keeping highest version; rank: curated first, then official vendor namespaces (namespace domain == root of remote URL host), then others; cache registry responses 24 h at `~/.mcpm/catalog-cache.json`. Offline → curated only with a `source: "bundled"` flag.
3. Protocol: `catalog.search {query, limit?}` → `.catalog([CatalogEntry])`; `servers.inspectURL {url}` → `.inspection(URLInspection)`; `servers.add` gains `autoDetectAuth: Bool` (default true for remote): daemon runs `inspect` before adding — `notMCP` → error with suggestion text; `authRequired` → set `auth` accordingly (oauth/header) unless params already set it; set `transport` from inspection. Tests: probe inspect against Hummingbird fakes (json endpoint, 401+WWW-Authenticate+PRM, HTML docs page + working `/mcp` sibling, legacy SSE endpoint), catalog normalization/dedupe/ranking from a fixture registry JSON, handler add with auto-detect.

## Stream B — app

4. Add sheet: debounce 400 ms after a URL paste → `servers.inspectURL`; status line: "Checking…", "MCP endpoint · needs sign-in (OAuth)" / "MCP endpoint · no auth" / "Not an MCP endpoint. Did you mean https://mcp.posthog.com/mcp? [Use it]" / "Unreachable"; Add disabled while notMCP; auth picker pre-set from inspection (still editable). After Add of an oauth server: toast/inline "Added. Sign in?" with a button → startAuth.
5. Catalog tab in the main window (sidebar/tab next to the grid): search field; results as cards (icon via `ServerIcon(name:kind:url:command:args:)`, name, description, kind + transport badge, "official"/"community" pill, auth hint); **Add** opens the Add sheet pre-filled (name, url/command, transport, auth, all clients on). Empty query shows the curated list.
6. Smart paste: recognize `claude mcp add --transport sse …` and bare `/sse` URLs → transport sse.

Smoke: add PostHog from the catalog → auth auto-detected (OAuth) → Sign in → Test shows tools. Paste the PostHog docs URL → blocked with the `/mcp` suggestion.
